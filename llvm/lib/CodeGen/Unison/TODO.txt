Unison CP-SAT Register Allocator — TODO
========================================

Global/Local Decomposition — Implementation Plan
-------------------------------------------------

Architecture:
- GlobalModel: one CpModelBuilder for cross-block decisions
- LocalModels[mbb_num]: one CpModelBuilder per MBB for scheduling + local allocation
- For cross-block vregs: TWO variables per vreg — one in GlobalModel, one in each
  LocalModel where it's live. Linked by a map {global_var → local_var}.

Variable creation:
- Cross-block vreg: global_var = GlobalModel.NewIntVar(domain)
                     local_var  = LocalModel.NewIntVar(domain)
                     Map records {global_var, local_var}
- Block-local vreg: local_var only (no global counterpart)
- UnisonInstr fields (Reg.Var, ChoiceVar, etc.) hold LOCAL variables
- Constraint builders see local variables, add constraints to local model

Global model constraints:
- Congruence (exit operand reg == entry operand reg)
- LiveInDef link (LiveInDef == shared Reg.Var when in register)
- Interference between cross-block vregs (not-equal from LiveIntervals)
- Interference between cross-block vregs and physreg defs
- Register class for cross-block vregs
- Objective: minimize spill cost

Local model constraints (per MBB):
- NoOverlap2D
- Data dependencies, anti-dependencies, ordering
- Register class for block-local vregs
- CopyOp activation, instruction selection
- Objective: makespan + copy cost

Solving:
1. Build all local models (constraints, no equalities yet)
2. Build global model
3. Iteration loop:
   a. Solve GlobalModel → GlobalResponse
   b. For each MBB:
      - Clone: PreAssigned = LocalModels[mbb].Clone()
      - For each cross-block vreg live in mbb:
          val = SolutionIntegerValue(GlobalResponse, global_var)
          PreAssigned.AddEquality(local_var, val)
      - Solve PreAssigned → local solution
   c. If any block infeasible → add nogood to GlobalModel, go to (a)
   d. Compute total cost = weighted sum of local costs
   e. Add constraint: cost < best so far
   f. Go to (a) until optimal or timeout
4. Generate code from combined solution

Key insight: CpModelBuilder::Clone() lets us reuse the base local model
across global iterations. Each iteration clones, adds equalities, solves.
No model rebuild needed.
